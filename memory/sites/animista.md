## Current
- Primary source for UI CSS animations: https://animista.net/.
- URL pattern for variants: `https://animista.net/play/<category>/<group>/<variant>`.
- Licensing: Generated CSS is FreeBSD licensed. Redistribution requires retaining copyright notice and license disclaimer.
