## Current
- Primary free source for **button/UI animation snippets** in web projects: https://uiverse.io/.
- Categories: buttons, cards, loaders, badges, toggles, hovers, checkboxes, avatars, search bars, etc. Each snippet = an `<html>` block with scoped CSS + optional inline JS; copy, adapt to the project token palette, drop in.
- **License/attribution:** verify the selected snippet’s license from its source and preserve required notices. Do not assume one blanket license.
- Used alongside `animista-ui-motion` (animista.net, FreeBSD CSS — keep the license notice) and the `transitions-dev` skill for deeper CSS transition work.
- When wiring UI animations (Type-A step 6, or any "improve/polish" task): source snippets here, adapt to tokens, respect `prefers-reduced-motion`, verify the animation actually plays in a live capture.
