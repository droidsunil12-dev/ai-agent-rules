- When the keep-alive re-dispatch chain runs a GitHub `cancel` POST against a run that has already ended, it returns **409 (Conflict)** — this is expected/harmless, not an error. Do not treat a 409 on cancel as a failure.
- On GitHub Actions, multiple `in_progress` runner dispatches can pile up at once when a new dispatch lands before the prior runner ever confirms up on the tailnet. Only track the **newest** dispatch you trigger; ignore older stragglers.
- After a re-dispatch, the new runner's Tailscale 100.x IP can take **6+ minutes** to appear (workflow queue + boot + `tailscale up`).
