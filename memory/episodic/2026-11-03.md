ChatGPT (free tier, browser) is able to fetch localhost URLs and use them as visual style reference — no CORS issue because the fetch happens on the ChatGPT side. This was the only way to complete the Pinterest→JSON style-extraction step for the KinePay banner pipeline.

## 2026-11-03 — ChatGPT browser file upload: DOM DataTransfer bypasses sandbox path errors

Attempting Playwright `setInputFiles()` with local images in the daemon fails with `Error: Path ... escapes the session directory`. Furthermore, ChatGPT's cloud servers cannot resolve `localhost` / `127.0.0.1` URLs served on the local machine.

The working solution to upload reference images to ChatGPT in browser: read the local file to base64 in Node/REPL, then inject the file into the ChatGPT DOM file input (`input[type="file"][accept*="image"]`) using a browser-native `DataTransfer` object:
```javascript
const dt = new DataTransfer();
dt.items.add(new File([blob], 'inspiration-banner.jpg', { type: 'image/jpeg' }));
input.files = dt.files;
input.dispatchEvent(new Event('change', { bubbles: true }));
input.dispatchEvent(new Event('input', { bubbles: true }));
```
This cleanly attaches the image file to ChatGPT's composer without any sandbox filesystem restrictions.
