## 01:03 Aside REPL keeps one persistent top-level scope; identifiers and evaluate-scope collide across calls
Reference: sessions.get("8fF8Jia1Xo0knSvJ")

## 18:32 PowerShell embedded in a GitHub Actions `run:` block: keep `-replace` subexpressions simple

## 23:08 Jarvis: `stt.engine = "browser"` (no server-side STT) vs `stt.engine = "auto"` (fallback order)

In `bridge/server.mjs` the `/stt` POST route has two conditions checked in sequence: first `STT_ENGINE === "google" || (STT_ENGINE === "auto" && GOOGLE_KEY)` routes to `geminiStt`; otherwise it falls through to the ElevenLabs Scribe path which requires `elevenKey()`.
