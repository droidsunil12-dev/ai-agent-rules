## 6:31 Durable quirks hit setting up a Google Apps Script Web App (site quirk)
(a) The Apps Script code editor is **Monaco**, not CodeMirror — typing line-by-line via `page.keyboard.type` double-applies auto-indent and pollutes the code; the clean path is `page.evaluate(c => window.monaco.editor.getEditors()[0].setValue(c), code)`. Read it back the same way via `getValue()`. (b) "New deployment" opens an OAuth "warning" page (first-time unverified app): click Advanced → "Go to ... (unsafe)" → on the consent page the "Select all" checkbox must be clicked or it silently continues with NO access ("You did not allow any access") — verify `input[type=checkbox]` checked=true on all rows before "Continue." (c) The deploy popup (OAuth tab) can't be attached via `attachBrowserTab` by its id; instead `openTab`/`page.goto` the Apps Script or OAuth URL in the agent's own tab — sign-in persists. (d) `read_file` on `dist/js/main.js` is the reliable way to read the submit handler (PowerShell `$_` / inline `$var` mangle through the bash tool, per the recurring note). (e) Clicking "Deploy" on a fresh web-app deployment **abandons the whole deployment** the moment it hits the OAuth "Authorize access" step — afterwards Manage deployments shows "No active deployment" and the Web app URL link is gone. The reliable sequence: complete the OAuth consent FIRST (the consent popup opens in a **user** tab that can't be attached; drive it via `openTab(consentUrl)` in a fresh agent tab, Advanced → "Go to ... (unsafe)" → on the consent screen click "Select all" then "Continue", watch for the "You did not allow any access" trap), return to the editor, THEN re-run Create deployment → Web app → Who-has-access=Anyone → Deploy. A second "Authorize access" prompt inside the deploy dialog is normal; it finishes once OAuth is done. (f) To read the full deployed Web app URL, the dialog **truncates** the displayed link text; read it via `document.querySelector('[role=dialog] a')` whose `href` matches `/macros\/s\/` and return `.href` (the full `.../exec` URL).
