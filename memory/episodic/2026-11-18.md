When writing 16 B2B SVG icons in a PowerShell script, two distinct PS pitfalls both hit:
1. `Join-Path $dir $k + ".svg"` parses as `Join-Path $dir ($k + ".svg")` correctly in intent, but in the actual run it produced the path `...\b2b-pay-vendor\+.svg` (treated `$k` as a subfolder) — the `+ ".svg"` binding made PS build a wrong leaf. **REPL identifier collision:** `const b2b` / `const s2` / etc. persist across repl calls in the persistent top-level scope. If you declared `const b2b` in an earlier call, a later `const b2b = ...` in the same session throws `SyntaxError: Identifier already declared`.
