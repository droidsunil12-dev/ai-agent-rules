## Kinepay icon extraction: two defect fixes + tooling

Reference: sessions.get("Sw6y6cF2FJ6ieGLy")

- **Two extraction defects found & fixed when turning the white-bg 3D icon sheets into trimmed transparent PNGs:**
  1. **Global "make near-white → transparent" punches holes through the icons.** The 3D icons use **white as a real material** (glossy white faces on the bot, copy, @-sign, check icons). Fix: remove background by **border-flood** — flood-fill the near-white pixels that are *connected to the image border* to transparent; interior white faces stay opaque.
  2. **Nearest-neighbor upscaling creates visible checkerboard/moiré.** The source sheet cells are small (~150–220px) but output is 512px, so this is an *upscale*. Nearest-neighbor sampling turns the smooth 3D gradient shading into a checkerboard. Fix: sample with **bilinear** interpolation.
- **Durable tooling note:** PowerShell `System.Drawing` (`LockBits`/`GetPixel`) is unreliable and too slow for 512×512 batch work. The working stack here is **Node.js + `pngjs`** (`npm install pngjs --no-save`): `PNG.sync.read(buffer)` to decode, `PNG.sync.write(png)` to encode (NOT `PNG.sync.decode`/`encode`). The 50 final icons live in `assets/images/icons/` (512×512, 4 corners A=0, ~90% transparent, bilinear-upscaled, border-flood white-removed) and are zipped to the session artifacts as `kinepay-icons.zip`.
