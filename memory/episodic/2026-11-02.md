## 18:54 CSS animation traps when building animated banners
Two recurring web-layout traps hit while building the animated banner: (1) an entrance animation that animates `transform` makes its element a containing block, so an absolutely positioned child resolves percentage `top/left` against that wrapper; if the wrapper has zero height, the child jumps out of bounds (fixed by giving the wrapper `position:absolute; inset:0` covering the stage); (2) in a flex-column layout, a declared `height` on a flex item is ignored when its `flex:1` basis is 0, so the scene collapses to 0px (fix: add `flex:none` alongside the explicit height). ## 22:05 Canvas taint workaround on file:// pages: inject image as base64 data URL
When compositing images onto a `<canvas>` via `page.evaluate` on a `file://` page, a same-directory relative `new Image()` with `src` loads fine (fires `onload`, correct dimensions) but any subsequent `canvas.toDataURL()` throws "Tainted canvases may not be exported" due to cross-origin/file-protocol taint, even with `crossOrigin='anonymous'` set. Working fix: `fs.readFile` the PNG on the Node side, base64-encode it, and pass it into the page as `window.__img = 'data:image/png;base64,...'` via a separate `page.evaluate` call, then use that data URL as the `Image.src` inside the composite `evaluate` — data URLs don't taint the canvas, so `toDataURL` export succeeds. Reference: sessions.get("NEe8chkD8J6kEhql")

## 22:10 Canvas 2D pixel-column feather mask is broken; use destination-in + linear gradient instead
An attempt to feather-mask a composited image's left edge by looping `ctx.drawImage` per-pixel-column with `ctx.globalAlpha` set per column does NOT work (the pixel-column `drawImage` into the same canvas is unreliable/ineffective, leaving a visible hard seam). Correct technique: draw the art onto an offscreen canvas, set `globalCompositeOperation = 'destination-in'`, paint a horizontal `createLinearGradient` (transparent → opaque) as the mask fill, then composite that masked offscreen canvas onto the final canvas with a normal `drawImage`. This produces a clean feathered edge without tainting the export path.
