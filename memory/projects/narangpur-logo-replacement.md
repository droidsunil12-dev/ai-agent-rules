## Gotcha
- **"Vertical to horizontal" = switch LAYOUT** (emblem-left + wordmark-right), NOT trim canvas. Filenames are misleading: "(vertical original)" refers to the stacked text layout, not canvas orientation. On an edit/rearrange logo task, confirm which *layout* the client wants before picking the source file.
- **Cache-bust gotcha:** before bumping `?v=X`→`?v=Y`, grep the HTML for the real versions in use. A replace that matches 0 lines is a no-op. Also: PowerShell `-replace` treats `?` as a regex special char — use plain `.Replace()` for literal cache-key updates, or escape the regex. Verify the replace actually took by re-reading the file.
- **Verify alpha before assuming background (HARD, 2026-11-17):** never assume an image's background (opaque vs transparent) from how it renders in a viewer. A transparent PNG shows the *viewer's* background, so "looks black/solid" is a false signal. Always probe the alpha channel (`$bmp.GetPixel(x,y).A`) before calling an asset "baked background." What looks "black" in a dark viewer can be the transparent channel.
- **Never change desktop while fixing mobile (HARD, 2026-11-17):** every mobile-only change uses a breakpoint-qualified class (`md:`/`lg:`/`xl:`) or `@media (max-width: 1024px)`. Before/after desktop verification via `getBoundingClientRect()` at 1280px. A `w-auto`/content-width shrink on a paired button is the classic leak (longer label wraps → unequal heights).
- **Surge `.cmd` shim broken:** use `node "C:\Users\Admin\AppData\Roaming\npm\node_modules\surge\bin\surge" . <domain>` (with `$env:CI="true"` + nodejs on PATH).
- Aside browser can't reach `localhost`/`file://`, so local build QA must be source-code inspection. **Exception:** after deploy to Surge, verify via `openTab` on the live URL + screenshot the changed element. `getBoundingClientRect()` at two viewports (390px + 1280px) is a reliable live-verification technique when CDP screenshots time out.
- **Browser window death (Kaggle sessions, 2026-11-17):** long REPL sessions typing into Kaggle cells kill the Aside task browser window; `openTab()`/`attachActiveBrowserTab()`/`listBrowserTabs()` all fail. Recovery = reopen browser from UI.
