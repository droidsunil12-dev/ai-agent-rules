# HOW TO FEED THESE FILES TO ANY AI IN THE FUTURE

This backup folder contains the complete operational brain, skills, memories, and quality guardrails of this assistant. Use the instructions below so any AI (ChatGPT, Claude, Cursor, Windsurf, or a fresh Aside instance) automatically adopts this exact workflow without needing repeated explanations.

---

### Option 1: Use with ChatGPT or Claude (Single Chat, Project, or Custom GPT)
1. **Quickest Method (Single Chat / Project Knowledge):**
   - Attach or copy the contents of **`SYSTEM-PROMPT-FOR-ANY-AI.md`** into the first message or the "System Prompt / Instructions" field.
   - For Claude Projects or ChatGPT Projects/GPTs, upload:
     - `SYSTEM-PROMPT-FOR-ANY-AI.md` (Core Operating Rules)
     - `AGENTS.md` (Task Router & Detailed Playbooks)
     - `memory/MEMORY.md` (Durable Rules & Real Examples)
     - `skills/master-ui-ux-design/SKILL.md` (UI/UX Craft Standards)
2. **Instruction Prompt to type:**
   > *"Adopt the rules and execution protocol defined in SYSTEM-PROMPT-FOR-ANY-AI.md and AGENTS.md. Enforce the 5-step cycle (Analyze-Plan-Checklist-Execute-Verify), the universal banner contrast rules, the Coolors vibrant palette protocol with live visualizer verification, and mobile 375px responsiveness. No extra unrequested work."*

---

### Option 2: Use in Cursor, Windsurf, Claude Code, or VS Code
1. Copy **`SYSTEM-PROMPT-FOR-ANY-AI.md`** to your project root and rename it to:
   - For **Cursor**: `.cursorrules`
   - For **Windsurf**: `.windsurfrules`
   - For **GitHub Copilot**: `.github/copilot-instructions.md`
   - For **Claude Code**: `CLAUDE.md`
2. Place **`AGENTS.md`** at the project root for automated workflow routing.

---

### Option 3: Restore or Migrate to Another Machine (Aside Browser)
To clone this exact setup to another machine or a fresh Aside installation:
1. Open the Aside account directory:
   - Current machine: `C:\Users\Admin\.aside\u\0\`
   - Alternate machine: `C:\Users\<Username>\.aside\u\0\`
2. Copy the contents of this folder into that account root:
   - Overwrite `AGENTS.md`
   - Overwrite `memory/`
   - Overwrite `skills/user/`
3. Restart Aside or open a new session. All skills, memories, and task routers will load immediately.
